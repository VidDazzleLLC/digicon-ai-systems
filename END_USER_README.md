# Digicon Installation Guide

Welcome to Digicon AI Systems! Follow these simple steps to install and start using the app.

## Prerequisites
- A Windows or Mac computer.
- Your unique `license.jwt` file provided after purchase.

## Installation Steps

1. Extract the `Digicon_v1.0.zip` file.
2. Inside, you will find the installer (`.exe` for Windows, `.dmg`/`.pkg` for macOS).
3. Double-click the installer. The process is completely automated (Zero-Touch Installation).
4. A shortcut named **Digicon** will be automatically created on your Desktop.
5. The application will launch automatically after installation.

## License Activation
1. On the first run, the app will ask for your license.
2. Select or drag-and-drop the `license.jwt` file.
3. The license will bind to your current computer. **Note:** Your license is non-transferable and can only be used on this specific machine.

## Reporting & Logs
You can generate performance and metrics reports from the app's settings menu, which will automatically export as CSV or JSON to your Downloads folder.

If you face any issues, our Self-Healing module will attempt to automatically resolve them!

## Background Agent & Shortcuts
- Digicon runs in the background to continuously act as your AI Agent.
- Access the dashboard anytime using the Global Shortcut: **Command+Shift+Space** (Mac) or **Control+Shift+Space** (Windows).
- You can also access it from your System Tray / Menu bar.
